VonWillingh builds starter / brochure websites and full custom web applications (see vonwillingh.co.za). Confirm which path fits — or a phased plan (site first, app later).

  • Starter / brochure website (info site, branding, contact & lead capture)
  • Business website with extras (gallery, blog, bookings, basic shop, etc.)
  • Custom web application (logins, dashboards, workflows, databases, integrations)
  • Phased: launch a website now, plan a custom app later
  • Unsure — need recommendation after discovery
  • Staff / admin portal
  • Client / customer portal
  • Bookings / appointments / jobs
  • Quotes, invoices, or CRM-style tools
  • Inventory / stock / orders
  • Payments / subscriptions
  • Integrations (WhatsApp, PayFast/Ozow, Xero/Sage, Google, other)
 
Suggestion: Custom apps are for when they outgrow a brochure site — e.g. staff logins, automated workflows, or a live cloud system (Next.js, Supabase, Vercel).
